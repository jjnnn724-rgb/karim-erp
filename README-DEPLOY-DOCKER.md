# 🚀 دليل نشر Karim ERP على Docker — جهاز آخر

## المتطلبات (على الجهاز الآخر فقط)
1. **Docker Desktop**: https://www.docker.com/products/docker-desktop/ — ثبّته وشغّله
2. اتصال إنترنت لأول تشغيل (بينزّ صور PostgreSQL وRedis وNode)

## خطوات التشغيل
```bat
:: 1) فك ضغط المجلد وادخل جواه
cd karim-erp

:: 2) شغّل النظام كامل (قاعدة بيانات + كاش + سيرفر)
docker compose up -d

:: 3) تابع أول إقلاع (بينشئ القاعدة ويطبق الجداول تلقائيًا)
docker compose logs -f app
```
لما تشوف السيرفر جاهز: افتح **http://localhost:5000** — النظام شغال بقاعدة جديدة فاضية.

## استعادة بيانات المطعم (النسخة المرفقة)
داخل الأرشيف: `database/restore-latest.sql` — آخر نسخة كاملة من بيانات المطعم (التاريخ في الاسم).

```bat
:: بعد أول تشغيل ناجح، ارجّع البيانات:
docker exec -i karim-erp-db psql -U postgres -d karim_erp < database\backups\karim-karim_erp-2026-09-29T15-51-42.sql

:: ثم أعد تشغيل التطبيق ليقرأ البيانات
docker compose restart app
```
⚠️ عملية الاستعادة **تستبدل** كل البيانات الحالية في الجهاز الآخر — نفذها على قاعدة فاضية فقط.

## للتعديل على الكود في الجهاز الآخر
1. عدّل أي ملف (backend أو frontend)
2. أعد البناء والتشغيل:
```bat
docker compose up -d --build
```
3. ملفات الواجهة (frontend) تتحدث فورًا بدون إعادة بناء لأنها تُخدم من المجلد مباشرة.

## إعدادات مهمة في .env
- **DB_PASSWORD**: كلمة مرور قاعدة البيانات — غيّرها للجهاز الآخر (غيّرها في .env وdocker-compose يستخدمها تلقائيًا)
- **JWT_ACCESS_SECRET / JWT_REFRESH_SECRET / EMPLOYEE_QR_SECRET**: مفاتيح التوقيع — موجودة، ويفضل توليد جديدة لكل بيئة
- **ALLOWED_ORGINS**: لو هتفتح النظام من أجهزة أخرى أضف المصدر

## تحذير أمني 🔐
- ملف **.env** يحتوي مفاتيح سرية وحساسية عالية — **لا ترفع الأرشيف على أي مكان عام** (تليجرام/جوجل درايف مشترك...) وابعتها بنقل مباشر موثوق
- البيانات المرفقة (نسخة القاعدة) تشمل بيانات الموظفين والحضور — نفس الحكم

## اختبار سريع بعد التشغيل
- `docker compose ps` — الثلاث حاويات (db / redis / app) تعمل
- `docker compose logs app --tail 20` — بدون أخطاء
- افتح http://localhost:5000 وسجل دخول بحساب من بياناتك المستعادة
