# ADR-008 — مدد (WPS): الحالة BLOCKED وخطة البديل

- **الحالة:** مقترح — بانتظار اعتماد المالك
- **التاريخ:** 2026-11-10
- **النطاق:** نظام حماية الأجور

## السياق

لا توجد في المستودع أي واجهة مدد، ولا وثيقة رسمية متاحة في هذه الجلسة تثبت
عناوين أو حقول أو آلية اعتماد. أي «تكامل» مكتوب الآن سيكون تخمينًا، وقد ينتهي
برفع ملف أجور مرفوض أو — الأسوأ — الاعتقاد بأن الرواتب مُودعة نظاميًا وهي ليست
كذلك.

## القرار

1. **`mudad` يبقى `BLOCKED` و`is_enabled=false`.** لا كود إرسال، ولا عميل HTTP،
   ولا مسار «تجريبي» يبدو كأنه تكامل.
2. **لا اختراع حقول أو عناوين.** كل ما يُبنى الآن هو تحضير محلي قابل للتحقق:
   - فحص اكتمال `payroll_runs` المُقفلة (لا صرف من مسودة).
   - تحقق صيغة IBAN السعودي (24 حرفًا تبدأ بـ`SA`) لكل موظف مستحق.
   - وجود رقم التأمينات ورقم الهوية في ملف الموظف.
   - تعريف الأجر الأساسي والبدلات من حقول الرواتب القائمة، بلا تغيير معادلة.
3. **مخرج بشري مُراجَع فقط:** تقرير/ملف أجور للقراءة، ببصمة SHA-256، يُنشأ
   بـ`compliance.view` ويُعتمد بـ`compliance.review`. لا رفع تلقائي، ولا وسم
   «مقبول من مدد».
4. **إعادة فتح البوابة شرطها دليل:** وثيقة واجهة رسمية + بيئة اختبار + رد
   قبول موثّق بتاريخ. عندها فقط يُحدَّث هذا ADR والتصنيف، ويُكتب عميل الإرسال.
5. **التأمينات وقوى** يُعاملان بالمنطق نفسه: `UNVERIFIED` حتى يوجد دليل، مع
   تحضير بيانات محلي فقط.

## العواقب

- لا نُنتج «تكامل مدد» وهميًا ولا نُطمئن المستخدم زائفًا.
- التحقق المحلي (IBAN/اكتمال) قيمة فورية حتى بدون واجهة.
- يبقى ملف الأجور الشهري عملًا يدويًا مُدارًا حتى يتغير التصنيف.

## البدائل المرفوضة

- **محاكي مدد داخلي:** يخلق وهم جاهزية وينتهك قاعدة «لا محاكاة كقبول».
- **تخزين بيانات بنكية إضافية بلا حاجة:** توسيع سطح المخاطر بلا مقابل.
- **تعديل جدول الرواتب لإرضاء حقول متخيَّلة:** يكسر قواعد مالية قائمة.

## تحديث 2026-11-10 — GATE 06 (تنفيذ محلي)

- نُفِّذ التحضير المسموح في البند 2: هجرة `147_employee_wps_bank.sql`
  (IBAN/جنسية/رقم تأمينات، إضافية وقابلة للعدم)، تقييم جاهزية لكل موظف،
  كشف أجور CSV للمراجعة ببصمة SHA-256، ومسارات `/api/integration/wps|gosi|qiwa`.
- **التصنيف لم يتغير:** `mudad` يبقى `BLOCKED` و`is_enabled=false`، ولا عميل
  HTTP ولا رفع تلقائي. لم يُبنَ ملف SIF ولم تُطبَّق نسب التأمينات على أي حساب.
