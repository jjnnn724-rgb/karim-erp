# ADR-009 — أسطح العرض: إعدادات V2 ثم V3

- **الحالة:** مقترح — بانتظار اعتماد المالك
- **التاريخ:** 2026-11-10
- **النطاق:** واجهة الامتثال في V2 وV3

## السياق

V3 يصبح الواجهة الأساسية 2026-11-16 06:00، لكن V2 يبقى متاحًا بعده. شاشة
إعدادات V2 الحالية (`frontend/app/js/v2/screens/settings.js`) تعرض أقسامًا:
`zatca`, `kot`, `cards`, `punch`, `server`, `backup`, `danger`. لا يوجد قسم
امتثال موحّد، وZATCA وحده يملك بطاقة. كاتب الشاشة الحالي يستخدم نمط
`sectionCard` وحقل كتابة مربوطًا بالأدوار.

## القرار

1. **قسم جديد في بطاقات V2 باسم «الامتثال السعودي»** يوضع بعد بطاقة ZATCA،
   بنفس نمط `sectionCard` القائم، ويُركَّب فقط لمن يملك `compliance.view`
   (أو admin). التفصيل في
   [v2-settings-design.md](../phase-0/v2-settings-design.md).
2. **بطاقة ZATCA القائمة تبقى كما هي.** لا تُدمج ولا تُعاد تسميتها في هذه
   المرحلة؛ القسم الجديد يعرض الحالة والصادر والسجل، ويشير إلى بطاقة ZATCA
   للإعدادات الحالية بدل تكرار الحقول.
3. **لا تُعرَض أسرار إطلاقًا.** حقول الاعتماد كتابة فقط، مع `rotated_at`
   وحالة الاعتماد. لا CSID ولا مفاتيح في HTML ولا في استجابات القائمة.
4. **لافتة حقيقة دائمة:** ما دام أي مزوّد غير `VERIFIED` تظهر لافتة صريحة
   «لا يوجد اعتماد حكومي إنتاجي موثّق لهذا المزوّد» مع حالته. لا شارة
   «متصل» أو «ناجح» بلا دليل.
5. **V3 لاحقًا:** بعد قلب 2026-11-16، يُنقل القسم إلى شاشة إعدادات V3 بنفس
   العقد (API نفسه)، بلا تغيير خلفي. لا تنفيذ V3 الآن.
6. **لا تغيير تنقّل V2:** لا عنصر قائمة جديد، ولا تغيير على `hidden_nav_pages`.
   الوصول ضمن شاشة الإعدادات القائمة.
7. **RTL ونصوص مختصرة:** العربية أولًا، بلا نصوص تعليمية أو تاريخ تصميم أو
   إشارات ADR داخل الواجهة (معيار V3 المعتمد). الأرقام والتواريخ بمنطقة زمنية
   آسيا/الرياض.

## العواقب

- المشغّل يرى الحقيقة (جاهز/مقيَّد/محظور) لا صورة تفاؤلية.
- تغيير V3 لا يفتح عملًا خلفيًا مزدوجًا؛ نفس الـAPI.
- قسم واحد يجمع الحالة عبر المزوّدات بدل بطاقات متفرقة.

## البدائل المرفوضة

- **بطاقة لكل مزوّد فورًا:** تكرر الهيكل قبل ثبوت أي مزوّد.
- **دمج ZATCA الجديدة داخل القديمة:** يخاطر بكسر شاشة مستخدمة حاليًا.
- **الاعتماد على V3 فقط:** يفصل المستخدمين الحاليين على V2 قبل القلب.
