# 🔍 تدقيق التعايش v2/v3 — لا تعارض نشط (2026-11-19)

طلب المالك: «مش عايز أي شيء قديم يعمل تعارض — كل شيء احترافي». دُققت نقاط التماس الفعلية بين الطبقتين بالأدلة:

| نقطة التماس | الحالة | الدليل |
|---|---|---|
| مسارات التقديم | ✅ مفصولة | ‏`/v3` → `backend/v3/static-routes.js` (راوتر مخصص)؛ `/app` → static منفصل؛ `/uploads`, `/updates` مستقلة |
| مفتاح الجلسة | ✅ لا تصادم | ‏v2 يستخدم `localStorage.token`؛ v3 يستخدم `karim_rt_v1` (refresh) والaccess في الذاكرة فقط — مفتاحان مختلفان على نفس Origin |
| Service Worker | ✅ لا تداخل | ‏v2 يسجل `/app/sw.js` بنطاق `/app/` فقط؛ **v3 بلا SW إطلاقًا** (لا تسجيل في main.tsx ولا vite.config) |
| لغة الواجهة | ✅ مشاركة مقصودة | `karim_lang` مشترك عمدًا (تفضيل مستخدم واحد عبر الطبقتين) |
| قلب المدخل | ✅ مُدار لا عشوائي | `frontend/v3/rollout.json` يُقرأ حيًا لكل نداء (`backend/rollout.js`)؛ switchAt مضى ⇒ v3 هو المدخل الأساسي، وv2 متاح تحت /app للفترة الانتقالية؛ تجاوز فوري بـV3_PRIMARY=1/0 |
| عقد API | ✅ مصدر واحد | الطبقتان تستدعيان نفس backend — لا عقود مكررة ولا ازدواج كتابة |
| أجيال الحزم القديمة | ✅ مُقلّمة | 471 ملف حزم ميت (9.6MB) أُزيلت بإغلاق مراجع كامل؛ 141/141 مرجعًا سليمًا |
| وثائق/لقطات مكررة | ✅ نُظفت | HORUS المكررة، لقطات md5-متطابقة، لقطة src القديمة (555 ملفًا) → حجر خارج المستودع |

## الخلاصة
«اللخبطة» التاريخية كانت **رواسب ميتة** (ملفات/لقطات/أجيال حزم) لا تعارضًا تشغيليًا — أُزيلت أو حُجرت بقرار المالك. التعايش الحالي **مقصود ومُدار**: v3 مدخل أساسي، v2 تحت /app بانتقالية موثقة، ولا نقطة تماس واحدة غير محكومة.

## خطة التقاعد النهائي لـv2 (قرار مالك)
عند اكتمال اعتماد v3 تشغيليًا: إزالة /app وsw.js القديمين بترحيل واجهة موثق (خطوة واحدة، قابلة للرجوع عبر git)، وإبقاء backend كما هو (يخدم الطبقتين بنفس العقد).
