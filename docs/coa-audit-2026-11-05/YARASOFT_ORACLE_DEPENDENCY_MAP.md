# 5. YARASOFT_ORACLE_DEPENDENCY_MAP.md — خريطة الاعتماد على YaraSoft/Oracle (READ-ONLY، بلا أي اتصال بهذه الجلسة)

## 1. الاتصال (المنسوخ من الكود — لم يُنفذ هذه الجلسة)
- المضيف: `YARASOFT_ORACLE_HOST` (افتراضي `192.168.1.188`) · Port `1521` · Service `ORACLE` · المستخدم `acc2026` (من `.env` الفعلي، مموّه) · **Thick mode إلزامي** (`C:/oracle/instantclient_23_0`).
- تسجيلات احتياطية: `_2` / `_3` تُستخدم تلقائيًا عند `ORA-01017` (خطأ كلمة مرور).
- Guard: `assertOracleReadOnly` يرفض أي SQL لا يبدأ بـ `SELECT`/`WITH` (كود `oracle-link.js:131-149`). **لكن الصلاحية الفعلية على مستوى المستخدم (SELECT-only grants) لم تُتحقق منها في هذه الجلسة — تحتاج مدير DB Oracle أو DBA YaraSoft.**
- Circuit breaker: 3 إخفاقات ← تُفتح الدائرة 45 ثانية مع `ORACLE_UNREACHABLE` (لا تعلق شاشات 15 ث).
- الإعداد الحي: `YARASOFT_ENABLED=true`, `DRY_RUN=false`, `LIVE=true`, `POLL_MIN=1`, `GL_BRIDGE` افتراضيًا true، cutover `2026-10-01`.

## 2. ماذا يُقرأ من Oracle (فقط)
| المسار | الملف | ما يُقرأ | الغرض |
|---|---|---|---|
| المرآة الكاشيرية | `yarasoft/mirror.js` | `CC_BILLS3`, `CC_BILL_ENTER3` (كاشير 1,3,4,5,6,9) | Upsert بمفتاح DOC_NO → `ys_mirror_orders` |
| المبيعات/الإيراد | `yarasoft/oracle-consume.js` + `oracle-full-import.js` | جداول BILLS/ITEMS/CUSTOMER/ASSTS/BALANCES → `ora_*` + `revenues(external_ref)` | استيراد idempotent + مقابل للمحاسبة |
| جسر GL | `yarasoft/gl-bridge.js` | لا يقرأ Oracle — يقرأ `revenues` المحلية ويرحّل Dr 1000/Cr 4000 | التشغيل اليومي |
| التقارير الحيّة | `yarasoft/yara-reports.js` | استعلامات تشغيلية حيّة (أقسام، كاشير اليوم، شهري) + stale ≤15 دقيقة عند الانقطاع | عرض تشغيلي — ليس ترحيلًا |
| التسوية | `finance-routes.js:668-735` | مقارنة `cost_gap` Oracle مقابل الدفتر | فحص فقط |
| الفواتير الإلكترونية | `ora_e_invoices` | ضرائب Yara — **لماذا القيد Dr 1000/Cr 4000 صافي بلا سطر ضريبة** | إيراد صافي فقط |

**لا يوجد أي INSERT/UPDATE/DDL موجه لـ Oracle في الكود.** كل ما كُتب على "Oracle" هو SELECT + نسخ مرآوي محلي.

## 3. النقاط التي تدخل YaraSoft في المسار المحاسبي (المسموح بقراءتها فقط)
1. `gl-bridge` — يرحّل قيود إيراد محليًا استنادًا لبيانات مستوردة من Oracle (قراءة سابقة) — المحاسبة نفسها محلية.
2. `oracle-data-routes` + `oracle-full-import` — نسخ للتدقيق/المقارنة (`ora_*`).
3. `cashier-sales-routes` / `cashier-monitor-routes` — عرض فقط من `ys_mirror_orders`.
4. `revenues` من الاستيراد — المصدر الفعلي لأكثر القيود حجمًا في الدفتر.

## 4. ما يعمل/ما لا يعمل عند انقطاع Oracle
- **تنقطع**: تغذية `revenues` الجديدة → يتوقف ترحيل إيراد الكاشير الجديد للدفتر + تقارير Yara الحيّة 503 + المقارنة الشهرية + اللحاق `sync-doctor`.
- **تستمر**: كل شيء داخلي في PostgreSQL — قيود، توازن، فترات، قوائم، إهلاك، تفاعل العملاء/الموردين، الموازنة، الإقفال اليومي، الإقرار الضريبي (من الدفتر).
- النظام **مصمم بفشل آمن** في كل نقاط Yara (flags + circuit breaker + stale snapshots).

## 5. نقاط خطر التكامل (للقرار)
1. **المبيعات المحلية (`pos_orders`) شبه فارغة** — البيع الحقيقي يمر عبر Yara فقط ⇒ دفتر كريم بلا Oracle لا يتلقى إيرادًا جديدًا. (خطر تشغيلي، لا حسابي.)
2. **1,447 قيدًا مزدوجًا (129,182.64) في 2026-10-05/06** — حدث فعلي سابق بسبب مفتاح معرّف غير ثابت؛ الإصلاح تم (external_ref). **أي تعديل مستقبلي على الجسر يجب أن يبقى idempotent على external_ref.**
3. **تقريب ضريبة الإيراد**: الجسر يرحّل صافي بلا سطر ضريبة (قرار متعمّد — ضريبة Yara تعيش في ora_e_invoices). هذا مقبول تشغيليًا لكنه يعني أن **إقرار الضريبة التشغيلي لا يقرأ من الدفتر كاملًا للإيراد**؛ يجب توثيقه كسياسة.
4. **قبل cutover 2026-10-01**: قيود افتتاحية مجمعة Cr 3100 — مقبولة كتسوية فتح، لا كتفصيل.
5. **الاعتمادية على الثقة بلوج مدراء**: لا يوجد تحقق دوري من أن حساب Oracle SELECT-only فعلًا (دوريًا). مطلوب إجراء DBA توثيقي.
6. **`YARASOFT_ORACLE_USER=acc2026` على جهاز الإنتاج** — كلمة المرور في `.env` بنص صريح مموّه؛ مطلوب تدوير دوري وسجل وصول (خارج نطاق المرحلة صفر).

## 6. المطلوب قبل المرحلة 2 (من منظور Yara)
- توثيق رسمي من DBA: Oracle ID SELECT-only (دليل grants) — شرط لإغلاق Phase 5/6.
- قرار المالك بشأن مصدر الإيراد: (أ) إبقاء الجسر + إلزام المتابعة، أو (ب) إلزام POS محلي للفرع. أي قرار يعمل محليًا — هو الأقرب لـ "PostgreSQL owns accounting".
- تقرير فشل الجسر/المزامنة ضمن بوابة متابعة يومية (dashboard + تنبيه).
- **لا إيقاف لـ YARASOFT_ENABLED ولا تغيير/حذف بيانات Oracle دون موافقة حرفية.**
