# دليل تطبيق EXE لكل جهاز — عميل موحد + سيرفر مركزي 🖥️

**Karim ERP — Universal Windows Client (توجيه v7.1 §5/LAW 05)**

جهاز واحد يحمل السيرفر وقاعدة البيانات، وكل جهاز آخر يأخذ **نفس تطبيق EXE** ويدخل بحسابه — والصلاحيات يحددها السيرفر عند كل تسجيل دخول. الجهاز لا يحمل أي أسرار (لا بيانات قاعدة بيانات، لا مفاتيح).

---

## 1) بناء ملف التثبيت (على جهاز السيرفر — مرة واحدة)

```powershell
cd C:\Users\RemoteHome\Desktop\k\karimabdelhamedeldsouky\karimabdelhamed12\karim-erp
npm run electron:build:nsis
```

- يستغرق دقائق، والمخرج في مجلد **`release/`**: ملف باسم مثل `مطاعم الشرفه العالمي Setup 4.7.0.exe`
- هذا **نفس الملف لكل الأجهزة** — لا يوجد ملف سيرفر وملف عميل منفصل؛ الوضع يُحدده ملف إعداد صغير (انظر أدناه)

## 2) تثبيت على جهاز السيرفر نفسه

ثبّت الـ EXE عادي — بدون أي خطوة إضافية. سيتصرف كما هو الآن: يشغّل قاعدة البيانات والسيرفر محليًا ويفتح الواجهة.

## 3) تثبيت على أي جهاز عميل (كاشير، حسابات، مخازن، إدارة...)

بعد تثبيت الـ EXE على الجهاز العميل:

1. انسخ ملف **`CLIENT-SETUP.bat`** من مجلد المشروع (أو من مشاركة `\\192.168.1.165\karim-erp`) إلى الجهاز العميل
2. شغّله (دبل كليك — لا يحتاج مسؤول):
   ```
   CLIENT-SETUP.bat
   ```
   أو بعنوان مختلف: `CLIENT-SETUP.bat https://100.110.41.80:5000`
3. ثبّت شهادة الأمان (مرة واحدة): افتح بالمتصفح `https://192.168.1.165:5000/app/Karim-Local-CA.crt` → Install Certificate → Local Machine → Trusted Root Certification Authorities
4. افتح تطبيق **Karim ERP** من قائمة ابدأ → يسألك تسجيل الدخول → ادخل بحسابك وصلاحياتك

**هذا كل شيء** — التطبيق على الجهاز العميل **نافذة ذكية فقط**: يعرض واجهة السيرفر المركزي، يتصل عبر HTTPS، وإذا السيرفر غير متاح يعيد المحاولة تلقائيًا بدل صفحة خطأ.

## 4) كيف يعمل الوضعان؟ (للفهم التقني)

| | وضع السيرفر (بدون ملف إعداد) | وضع العميل (مع ملف الإعداد) |
|---|---|---|
| قاعدة البيانات | يشغّل PostgreSQL محليًا | لا شيء — ممنوع اتصال مباشر (LAW 03/04) |
| خدمات الخلفية | يشغّلها | لا شيء |
| ما يعرضه | `http://127.0.0.1:5000` | `https://عنوان-السيرفر:5000` |
| التسجيل والصلاحيات | من قاعدة البيانات المحلية | **من السيرفر عند كل دخول** |
| تحديد الوضع | افتراضي | وجود `server-target.json` بجانب التطبيق أو في `%APPDATA%\karim-erp` |

- **إرجاع جهاز لوضع السيرفر**: احذف `%APPDATA%\karim-erp\server-target.json`
- **تغيير عنوان السيرفر لاحقًا**: شغّل `CLIENT-SETUP.bat` بالعنوان الجديد

## 5) الأمان المطبق (LAW 16 + عقد §36)

- `nodeIntegration: false` + `contextIsolation: true` + `webSecurity: true` — بلا أي تنفيذ محلي
- الشهادة: المسار الدائم تثبيت CA على كل جهاز؛ وهناك حماية إضافية في وضع العميل تقبل شهادة **السيرفر المضبوط حصرًا** وترفض أي شيء آخر
- لا يحتوي التطبيق على كلمات مرور قاعدة البيانات أو مفاتيح — كلها تبقى على السيرفر

## 6) الخلاصة التشغيلية

| الجهاز | ما تثبّت عليه | ما تشغّله بعده |
|---|---|---|
| السيرفر | EXE فقط | لا شيء (كما هو الآن) |
| أي جهاز آخر على الشبكة | EXE + `CLIENT-SETUP.bat` + الشهادة | دخول بحساب كل مستخدم |

> 🚀 **المرحلة القادمة (بوابة G4 وفق التوجيه §26–§36):** منظومة التحديث الذاتي اللاني — KARIM-Updater.exe يوزّع الإصدارات الجديدة على كل الأجهزة من السيرفر مع توقيع رقمي وتراجع آمن — بدل النسخ اليدوي.
