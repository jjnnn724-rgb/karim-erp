# karim ERP v4.7.0 — إصدار كاشير البوفيه المفتوح

> مطاعم الشرفه العالمي — نظام إدارة الموارد المتكامل
> الحزمة نظيفة تمامًا: بدون node_modules، بدون قاعدة بيانات حية، بدون نسخ احتياطية قديمة، وبدون ملف .env (أنشئه من .env.example)

## ما الجديد في هذا الإصدار

### كاشير البوفيه المفتوح (الميزة الرئيسية)
البيع **بعدد الأشخاص لا الأصناف** — كل فاتورة تسجّل الكبار والصغار والضيافة:

- **شاشة بيع مخصّصة**: بطاقات أفراد كبيرة مناسبة للمس (كبار 120 / أطفال 60 / ضيافة مجاناً) — الأسعار قابلة للتعديل من داخل الكاشير
- **فئات مخصّصة**: أضف فئات جديدة (مثال: عشاء مسائي) بأسعار وضريبة مستقلة، مع تعطيل/تفعيل دون فقدان سجل المبيعات
- **عداد حي** ينبض في رأس الشاشة: أفراد اليوم، الإيراد، الفواتير، أفراد الوردية الحالية — يحدث فوريًا بعد كل بيع
- **اسم العائلة/المناسبة**: حقل اختياري يُخزَّن على الفاتورة ويظهر في سجل الفواتير
- **فواتير البوفيه المخزنة**: تبويبان — المعلّقة (استرجاع/حذف) وفواتير اليوم (تفصيل الأفراد لكل فاتورة + حالة الصدور)
- **تقرير البوفيه اليومي** قابل للطباعة: الإيراد المحصل (شامل الضريبة) + ضريبة القيمة المضافة + صافي الإيراد + متوسط الفرد + التوزيع الساعي + طرق الدفع + أداء الكاشيرين + الملغاة والمعلقة
- **وراثة كاملة لمحرك البيع العام**: ZATCA (فسيور/تقارير)، الطباعة، الورديات ودرج النقد، Idempotency ضد التكرار، الخصومات

### إصلاحات جوهرية مكتشفة بالاختبار الحي
1. `/live` كان يفشل 500 دائمًا (خطأ SQL: معامل `$2` بدون `$1`) — أُصلح
2. قسم البوفيه لم يكن يُنشأ في سجل POS (`pos_departments`) فترجع كل التقارير صفرًا — يُنشأ الآن تلقائيًا مربوطًا بالقسم القديم
3. توحيد أساس الإيراد بين العداد الحي وملخص الوردية والتقرير اليومي (محصل شامل الضريبة + صافي + ضريبة منفصلة)
4. حماية تكرار أسماء الفئات في الإنشاء وإعادة التسمية وإعادة التفعيل

### إصلاحات النسخ السابقة المضمّنة (4.6)
- حماية TOCTOU في Idempotency، حظر الفواتير السالبة، تحويل الوحدات باتفاقية الكثافة، إصلاح 9 ملفات كاشير، إصلاح الواجهة (إرجاع المطبخ، تفاصيل القسم، XSS شامل)، Electron وPowerShell وWindows 11، ترحيلات قاعدة البيانات، وتقرير التدقيق الشامل

## التشغيل السريع

```bash
# 1) الاعتماديات
npm install

# 2) الإعدادات
copy .env.example .env   # ثم عدّل DB_PASSWORD وJWT_SECRET

# 3) قاعدة البيانات (يُنزّل PostgreSQL 16 محليًا تلقائيًا)
npm run setup:db          # أو: node database/scripts/download-pg.js

# 4) الإقلاع
npm start                 # أو: node scripts/watchdog.js للمراقبة الكاملة
```

- الدخول الافتراضي: `admin` (كلمة المرور تُضبط أول تشغيل — راجع scripts/reset-preview-admin.js)
- شاشة الكاشير: `http://localhost:3000/app/pos.html`
- شاشة النظام: `http://localhost:3000/`
- اختبار البوفيه حيًا (اختياري): يشغّل 42 تحققًا شاملًا على نقاط النهاية
