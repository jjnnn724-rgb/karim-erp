# تقرير تسليم مطاعم الشرفة العالمية

## نطاق الفحص
تم فحص ملفات الخادم والواجهة وElectron ومسارات الكاشير والمخزون والمطبخ والموارد البشرية وسكربتات قاعدة البيانات. جميع كيانات الأعمال الرئيسية تُحمّل وتُحفظ عبر PostgreSQL من خلال واجهات API المصادق عليها. لا توجد استخدامات فعلية لـ `localStorage` أو `sessionStorage` أو `indexedDB` لتخزين بيانات الأعمال.

يحتفظ النظام بجدول `app_state` داخل PostgreSQL للتوافق مع الإصدارات السابقة وبعض تفضيلات الواجهة، وليس كبديل عن الجداول العلائقية. أما المبيعات والمخزون والتحويلات والوصفات والموظفون والحضور والرواتب والجرد والإنتاج فتُدار من جداولها ومساراتها الخاصة في قاعدة البيانات.

## المثبت
تم إنتاج مثبت Windows بصيغة NSIS باسم:

`Al-Shorfa-International-Restaurants-Setup-3.1.0.exe`

المثبت يضم تطبيق Electron، خادم Express، ملفات الواجهة، ملفات الهجرة، وPostgreSQL Portable الخاص بـ Windows x64. عند تشغيل التطبيق، يقوم Electron بإدارة دورة تشغيل PostgreSQL محليًا، ثم يشغل خادم النظام ويفتح الواجهة. قاعدة البيانات تُقيد على localhost ولا تُعرض مباشرة على الشبكة؛ الوصول من أجهزة الشبكة يكون عبر خادم Express المصادق عليه.
