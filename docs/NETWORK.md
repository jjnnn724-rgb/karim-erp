# دليل إعداد الشبكة المحلية (Network Setup Guide)

يشرح هذا الدليل كيفية إعداد جهاز الخادم والأجهزة العميلة لضمان اتصال سلس عبر الشبكة المحلية (LAN) دون أي مشاكل.

## 1. كيف تعمل الشبكة المحلية للنظام؟
النظام يعمل بنموذج الخادم والعميل (Client-Server Model):
- **الخادم (Server)**: هو الكمبيوتر الرئيسي الذي يتم تشغيل النظام عليه (يحتوي على قاعدة البيانات وخدمة الـ Backend). يستمع هذا الخادم إلى عنوان `0.0.0.0` مما يعني أنه يقبل الطلبات من أي جهاز متصل بنفس شبكة الـ Wi-Fi أو الكيبل (Ethernet).
- **العملاء (Clients)**: هي الهواتف المحمولة أو أجهزة الكمبيوتر الأخرى الموجودة في المطعم أو الفندق (الكاشير، المطبخ، المستودع). لا تحتاج لتثبيت أي شيء سوى الدخول للرابط.

## 2. كيفية معرفة عنوان IP للخادم؟
بمجرد تشغيل النظام بالأمر `node scripts/start.js`، ستظهر لك العناوين المتاحة تلقائياً. 
للتحقق يدوياً يمكنك استخدام أداة اكتشاف الـ IP التي تم إعدادها في المشروع:
```bash
node scripts/show-ip.js
```
سيبحث هذا السكربت عن عنوان IPv4 المحلي الخاص بجهاز الخادم (مثال: `192.168.1.15`) ويطبعه لك، كما أنه يُحفظ في ملف `network-info.txt`.

## 3. السماح للنظام عبر جدار الحماية (Firewall)
غالباً ستقوم أنظمة التشغيل (مثل Windows) بحظر الاتصالات الواردة لحماية جهازك. يجب السماح للمنفذ رقم `5000` باستقبال البيانات.

### في نظام Windows
1. ابحث عن `cmd` في قائمة ابدأ، انقر عليه بزر الفأرة الأيمن واختر **Run as administrator**.
2. انسخ والصق الأمر التالي واضغط Enter:
```cmd
netsh advfirewall firewall add rule name="karim ERP LAN" dir=in action=allow protocol=TCP localport=5000
```
سيرد عليك بكلمة `OK`، وبذلك يكون جهازك مستعداً.

### في نظام Linux (UFW)
إذا كان خادمك يعمل بنظام Ubuntu أو توزيعات Linux المشابهة:
```bash
sudo ufw allow 5000/tcp
```

### في نظام macOS
macOS غالباً ما يطلب منك السماح للبرنامج عند محاولة تشغيله. في حال لم يطلب، يمكنك تمكينه عبر خيارات جدار الحماية في الإعدادات أو عن طريق ملف الـ `pf.conf`:
```bash
# للمحترفين فقط
echo "pass in proto tcp from any to any port 5000" | sudo pfctl -f -
```

## 4. استكشاف أخطاء الشبكة الشائعة وحلولها
| المشكلة | السبب المحتمل | الحل |
|---|---|---|
| صفحة الويب لا تفتح أبداً في العميل وتستمر بالتحميل | جدار حماية جهاز الخادم يمنع الاتصال | نفذ خطوة السماح عبر الـ Firewall كما هو موضح أعلاه. |
| عنوان الـ IP للخادم يتغير كل يوم | موجه الشبكة (Router) يعين الـ IP بشكل ديناميكي (DHCP) | يُنصح بالدخول لإعدادات الراوتر وتثبيت IP محدد لجهاز الخادم (Static IP Assignment)، حتى لا يتغير الرابط يومياً. |
| رسالة CORS Policy أو Network Error تظهر في الكونسول | الخادم متوقف أو إعدادات الشبكة تغيرت | تأكد أن سكربت الخادم ما زال يعمل في الشاشة السوداء بالخادم. تأكد من أن جهاز العميل متصل بنفس الـ Wi-Fi. |

## 5. الأمان على الشبكة المحلية
هذا النظام مصمم للشبكة الداخلية الموثوقة (LAN). 
- **لا تقم بتمرير المنفذ للإنترنت (Port Forwarding)** دون إضافة طبقات حماية للمصادقة وتشفير SSL (HTTPS)، حيث أن التطبيق الحالي لا يعتمد JWT ويفترض أمان الشبكة الداخلية بالكامل.
