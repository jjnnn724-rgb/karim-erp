# دليل تشغيل النظام من أي جهاز على الشبكة 🌐

**Karim ERP — وصول LAN كامل لكل الأجهزة (كمبيوتر، تابلت، موبايل)**

النظام مهيأ مسبقًا لذلك بالكامل — يتبقى تفعيلان فقط على السيرفر ثم خطوات بسيطة على كل جهاز.

---

## 1) على السيرفر (مرة واحدة — دقيقتان)

شغّل من جهاز السيرفر (RemoteHome) الملف الموجود في مجلد المشروع:

```
OPEN-LAN-ACCESS.bat
```

(كليك يمين → **تشغيل كمسؤول** — سيطلب الموافقة تلقائيًا)

هذا السكربت:
- يفتح جدار الحماية للمنفذ **5000** على كل بروفايلات الشبكة (خاصة/عامة/نطاق)
- يطبع لك **عناوين السيرفر** — استخدم عنوان الشبكة المحلية (مثل `192.168.1.165`)
- يختبر أن السيرفر يستجيب محليًا

## 2) عنوان الوصول من أي جهاز

```
https://192.168.1.165:5000
```

> ⚠️ ثبّت عنوان السيرفر: اجعل `192.168.1.165` محجوزًا في راوتر (DHCP Reservation) حتى لا يتغير العنوان يومًا.

## 3) على كل جهاز عميل (مرة واحدة لكل جهاز)

### أ) تثبيت شهادة الأمان (يلغي تحذير المتصفح تمامًا + يفعّل أيقونة التطبيق)

1. افتح في المتصفح: `https://192.168.1.165:5000/app/Karim-Local-CA.crt`
2. نزّل الملف → دبل كليك عليه → **Install Certificate**
3. اختر **Local Machine** → Next → **Place all certificates in the following store** → Browse → اختر **Trusted Root Certification Authorities** → Finish
4. **أغلق المتصفح كاملًا وافتحه من جديد**

### ب) الدخول للنظام

افتح `https://192.168.1.165:5000` → سجل الدخول كأي مستخدم بصلاحياته.

> بديل سريع بدون تثبيت الشهادة: عند التحذير اضغط **Advanced → Proceed** — يعمل، لكن يفضل تثبيت الشهادة لأن بعض مزايا التطبيق (أيقونة الشاشة الرئيسية) تحتاج اتصالًا موثوقًا.

## 4) على الموبايل والتابلت 📱

بعد تثبيت الشهادة وفتح الموقع:
- **أندرويد (Chrome)**: قائمة ⋮ → **Add to Home screen** → تظهر أيقونة تطبيق تعمل ملء الشاشة
- **آيفون (Safari)**: زر المشاركة ⟶ **Add to Home Screen**

## 5) شاشات الكاشير

نفس العنوان على أي جهاز: `https://192.168.1.165:5000/pos.html` أو من داخل النظام — الهوية والصلاحيات يحددها تسجيل الدخول (السيرفر هو مصدر الصلاحيات الوحيد).

---

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| الصفحة لا تُفتح من جهاز آخر | شغّل `OPEN-LAN-ACCESS.bat` كمسؤول على السيرفر (الجدار هو السبب الأشهر) |
| تحذير شهادة أحمر | ثبّت الشهادة كما في الخطوة 3-أ (أو Advanced → Proceed مؤقتًا) |
| العنوان توقف فجأة | تغيّر IP السيرفر — اطبع العنوان الجديد بـ `OPEN-LAN-ACCESS.bat` أو ثبّت DHCP |
| بطء على أجهزة كثيرة | طبيعي حتى ~20 جهازًا متزامنًا (مسبح قاعدة البيانات 60) — لاحقًا نرفع القياس في G4 |
| التطبيق فتح قبل وما زال قديمًا | Ctrl+Shift+R تحديث قوي (الإصدار يُدار تلقائيًا بعد أول تحديث) |

## ملاحظات أمنية (وفق عقد المعمارية)

- قاعدة البيانات **لا تُفتح للشبكة إطلاقًا** — الأجهزة تتصل بالسيرفر فقط عبر HTTPS
- كل الصلاحيات يحددها الخادم عند تسجيل الدخول — الجهاز مجرد واجهة
- الوصول عبر Tailscale (خارج المكتب) يعمل أيضًا: `https://100.110.41.80:5000`
