**القراءة الصادقة للأرقام:** V3 يفوق V1/V2 تقنيًا (نوع البيانات، عقد واضح، اختبارات، zero-scroll POS, لوحات امتثال حيّة)، لكن **التغطية الوظيفية** لا تزال دون V2 في ثلاثة محاور: (أ) الاحتراف في لوحة الإدارة، (ب) مباشرةً الكشوف والتقرير، (ج) القرار تحت الضغط (كاشيرات)، و(د) التكامل مع فواتير المحتوى القديم (إن وُجد).

**عدد الفجوات الوظيفية الجوهرية المتبقية لـV3 = 9** (تفاصيل §4). كل فجوة مرتبطة بمهمة وكل مهمة لها مشروعية تنفيذ مؤجلة بقرار المالك.

## ٣. قراءة سريعة لما يميز V3 عن V1/V2

**أشياء تمتلكها V3 فقط:**
1. `/bank-rec` (مطابقة البنك الآلي، إدخال/إخراج/فروق — كاملة عبر `/api/accounting/bank-rec`)
2. `/compliance-center` (تجميع GOSI/WPS/رواتب/قوى في لوحة واحدة)
3. `/command-center` (مؤشر موحد للالتزام + تنبؤ بالمخاطر + رابط للوحدات)
4. `/accounts` و`/journal` (قارئان جددا فوق نفس القاعدة — V3 React عوضًا عن جدول جامد)
5. `/vat-return` مع ورقة عمل خانات زاتكا + مطابقة أرصدة افتتاحية/ختامية + «غير مسجّلة» بدل أصفار مضللة
6. **React native UI** (TanStack Router، shadcn/ui، Tailwind) مع اختبارات سلوكية 181 ملفًا
7. **100dvh zero-scroll POS** مع تبويبات طلبات وF-keys
8. جودة البيانات: كشف «فجوات» الصفريات (كل ما غيره0 مرئي) في كل الشاشات المالية
9. PWA (`manifest.webmanifest`) + طباعة A4 بهوية واحدة (`PrintActions`)
10. **Attendance portal revamp**: وجهة عالمية للموظف مع `!faceStrict` + استعداد البوابة لـiPad وهواتف أقدم
