# التسليم النهائي — مطاعم الشرفة العالمية

## ما تم تصحيحه

تمت إضافة وضع تشغيل headless داخل Electron باستخدام الوسيط `--service`. في هذا الوضع لا تُفتح نافذة رسومية ولا Tray، ويقوم التطبيق بتشغيل PostgreSQL Portable وخادم Express فقط، مع إيقاف آمن عند إيقاف الخدمة.

أضيف مشغل WinSW x64 باسم `AlShorfaERPService.exe` مع ملف إعداد `AlShorfaERPService.xml`. يقوم مثبت NSIS بتسجيل الخدمة `AlShorfaERP` وتشغيلها تلقائيًا بعد التثبيت، مع إعداد إعادة تشغيل تلقائية عند الفشل، وتأخير بدء الخدمة، وتدوير سجلات الخدمة. كما يزيل المثبت الخدمة عند إلغاء التثبيت.

## SmartScreen والتوقيع

لم تتم إضافة أي تجاوز أو تعطيل لـ SmartScreen؛ ذلك ليس مسارًا آمنًا أو احترافيًا. المثبت الحالي جاهز للتوقيع الرسمي، لكن لا توجد شهادة Code Signing خاصة بالناشر داخل بيئة البناء. لتقليل التحذيرات بطريقة صحيحة، يجب توقيع المثبت والتطبيق بشهادة مرتبطة بالاسم القانوني للناشر. الإرشادات موجودة في `CODE_SIGNING.md`، ويستخدم electron-builder متغيري `CSC_LINK` و`CSC_KEY_PASSWORD`.

## الملفات

المثبت: `Al-Shorfa-International-Restaurants-Setup-3.1.0.exe`

نسخة المشروع الكاملة المصححة: `Al-Shorfa-ERP-FULL-CORRECTED.zip`

ملف SHA-256 للمثبت مرفق باسم `Al-Shorfa-International-Restaurants-Setup-3.1.0.exe.sha256`.

## ملاحظة اختبار Windows الحقيقي

تم التحقق من بنية المثبت ووجود ملفات الخدمة وقاعدة البيانات وتشغيل اختبارات المشروع. لا تزال تجربة النقر والتثبيت الكامل على Windows حقيقي هي الاختبار النهائي المطلوب، لأن بيئة البناء الحالية لا توفر نظام Windows أصليًا. بعد تثبيت نسخة موقعة على Windows، يجب التحقق من ظهور خدمة `AlShorfaERP` في `services.msc`، وتشغيلها، ثم فتح `http://127.0.0.1:5000` وتسجيل الدخول.
