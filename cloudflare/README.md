# الوصول الخارجي الآمن — نظام مطاعم الشرفه العالمي

تم تجهيز Cloudflare مسبقًا للنطاق `erp.osirisegypt.com` مع Cloudflare Access. لا يتم فتح PostgreSQL أو منفذ ERP مباشرة على الإنترنت؛ يجب أن يعمل `cloudflared` كخدمة على جهاز Windows الذي يشغّل النظام داخل المطعم.

## الحالة الحالية

- النطاق: `https://erp.osirisegypt.com`
- Tunnel: `karim-tunnel`
- الوجهة داخل الخادم: `http://127.0.0.1:5000`
- DNS: CNAME موجود ومحمّي عبر Cloudflare
- الحماية: Cloudflare Access يطلب بريدًا مصرحًا به قبل الوصول

## تثبيت الموصل على خادم Windows

1. ثبّت `cloudflared` من صفحة Cloudflare الرسمية على جهاز الخادم.
2. من Cloudflare Zero Trust افتح **Networks → Tunnels → karim-tunnel**، ثم اختر **Add a connector** وانسخ أمر التثبيت أو رمز النفق. لا تضع الرمز في Git أو داخل ملف المشروع.
3. افتح PowerShell بصلاحية Administrator داخل مجلد المشروع وشغّل:

```powershell
.\scripts\install-cloudflare-tunnel.ps1
```

سيطلب السكربت رمز النفق بشكل مخفي، ويتحقق من وجود `cloudflared`، ثم يثبت الخدمة ويشغلها تلقائيًا مع Windows.

4. تأكد أن النظام المحلي يستجيب على `http://127.0.0.1:5000/api/health`.
5. اختبر من خارج شبكة المطعم: `https://erp.osirisegypt.com`.

## سياسة التحديث

لا يتم رفع ملفات مباشرة إلى مسار التشغيل ولا تعديل قاعدة البيانات يدويًا. ضع حزمة إصدار ZIP في مصدر HTTPS خاص، مع ملف SHA-256 منفصل، ثم شغّل `scripts/update-production.ps1` على خادم Windows. السكربت:

- يتحقق من SHA-256 قبل التثبيت.
- ينشئ نسخة احتياطية لقاعدة البيانات والملفات الحالية.
- يوقف خدمة النظام بأمان.
- يستبدل ملفات الإصدار دون حذف مجلد البيانات أو النسخ الاحتياطية.
- يشغل الترحيلات.
- يفحص `/api/health`.
- يعيد التشغيل، ويحتفظ بنسخة يمكن الرجوع إليها عند الفشل.

Cloudflare Tunnel ليس قناة لرفع التحديثات؛ هو قناة وصول فقط. هذا الفصل يقلل خطر تنفيذ ملف غير موثوق على خادم الإنتاج.
